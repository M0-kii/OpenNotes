# Roadmap

The next round of work focuses on keeping notes safe and making the editor
dependable across desktop platforms.

- Test closing, recovery after a crash, and input-method composition in the native
  Windows, macOS, and Linux apps.
- Add database backups and note import/export.
- Improve error handling for folders, reordering, reminders, and settings.
- Test selection, undo, and large notes in the editor on each platform.
- Verify migration and recovery for older mind maps before retiring the legacy
  editor.
- Profile large note libraries and split the frontend bundle where it helps.

Cloud sync and accounts aren't scheduled yet. For now, notes stay on your computer.
